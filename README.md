# java-racingcar-precourse

## 구현할 기능 목록
1. **입력 기능**
   - 경주할 자동차 이름을 입력 받기(쉼표(`,`) 구분, 각 이름 1~5자)
   - 시도할 횟수 입력 받기(정수, 1 이상)
   
2. **입력값 검증**
    > 예외는 `IllegalArgumentException` 을 발생시킨 후 애플리케이션 종료한다.(System.exit() 호출 금지)
    - 자동차 이름이 비어있거나 `5자`를 초과 시 예외 발생
    - 시도 횟수가 정수가 아니거나 `0 이하`일 경우 예외 발생

3. **자동차 경주 로직**
    - Car 객체 생성(이름, 위치)
    - 0~9 사이의 난수 생성
      - 값이 `4 이상`이면 자동차 전진
    - N회 라운드 반복 및 자동차 이동 거리 갱신
    - 최종 우승자 계산 (가장 많이 이동한 자동차 찾기, 복수 가능)
   
4. **출력**
    - 각 라운드마다 자동차 이동 결과 출력 (`이름 : ---`)
    - 최종 우승자 출력(복수 시 쉼표(`,`) 구분)
